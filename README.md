# Mac Menubar Calendar

Mac Menubar Calendar 是一個為 macOS 設計的原生、輕量級純 Menubar 行事曆檢視應用程式。

## 特色功能

- **純 Menubar 體驗**：常駐於頂部 Menubar，即時顯示當天日期數字，不佔用 Dock 圖示。
- **連續 28 天網格檢視**：以 7 欄 × 4 列排列顯示從指定起始日起的連續 28 天行程，不受月份邊界限制。
- **直覺導覽**：支援上一週、下一週快速翻頁，並提供一鍵「回到今天」。
- **事件摘要與溢位**：直接在日期格顯示事件標題與行事曆色彩標記，動態計算可容納數量並提供「還有 N 筆」單日展開清單。
- **行程詳情與 Apple「行事曆」整合**：提供標題、時間、行事曆與地點等限定欄位檢視，並可快速跳轉至 Apple「行事曆」App 繼續操作。
- **行事曆篩選**：自動讀取 macOS 已設定之行事曆（包括已同步的 Google 日曆），支援個別勾選與偏好記憶。
- **彈性視窗與釘選**：支援自由縮放視窗尺寸並自動保存；提供釘選功能使視窗在失焦時保持顯示。
- **外觀與在地化**：支援跟隨系統、淺色與深色外觀；提供繁體中文與英文在地化介面。
- **輔助使用友好**：完整支援 VoiceOver 語意朗讀、鍵盤焦點導航、動態字級與高對比模式，資訊不單依賴顏色表達。

## 安全與隱私承諾

- **唯讀保護**：應用程式架構採嚴格唯讀設計，不提供任何建立、修改或刪除行程的途徑。
- **純記憶體處理**：行程內容僅在記憶體中顯示與快取，絕不寫入磁碟資料庫或持久化儲存。
- **零遙測與資料收集**：無任何分析代碼、無崩潰回報上傳、不存取網路進行未授權傳輸。
- **最小權限 App Sandbox**：嚴格限制於 App Sandbox 內執行，僅申請讀取行事曆必要的 Sandbox Entitlement。
- **本機偏好保存**：所有使用者設定（選取的行事曆、視窗尺寸、外觀、登入啟動等）皆只保存在本機 `UserDefaults`，不使用雲端同步。

## 系統需求

- macOS 15.0 Sequoia 或更新版本
- Apple Silicon Mac（M1 / M2 / M3 / M4 系列晶片）
